Mathematical Formulation

Pressure Situation Reconstruction & PRI Methodology

Defensible delivery-level situational modeling without black-box bias.

Dynamic Ball Pressure Formula (P_ball ∈ [0, 100]):
Every delivery is assigned a pressure index based on required run rate (RRR), wickets lost, balls remaining, target score, and innings phase.
Innings 2 (Chasing):
P_ball = 0.40 * clip((RRR - 6.0)/8.0, 0, 1) + 0.25 * clip(W_lost/7.0, 0, 1) + 0.20 * clip((120 - B_legal)/60.0, 0, 1) + 0.15 * clip((Target - 140.0)/80.0, 0, 1)

Innings 1 (Setting Total):
P_ball = 0.45 * clip((W_lost - 2)/6.0, 0, 1) + 0.35 * (1.0 if over >= 16 else (0.5 if over < 6 else 0.2)) + 0.20 * clip(CR - 8.0/6.0, 0, 1)
Bayesian Sample-Size Shrinkage Formula:
w_sample = N_pressure / (N_pressure + 60.0)
PRI_final = w_sample * PRI_raw + (1.0 - w_sample) * 50.0
Fielding Data Disclosure:
The official proprietary dataset includes wicketkeeper fielding records (stumpings and caught behinds) but omits delivery-level fielder tags for outfield catches and run-outs. Accordingly, outfield fielding analysis is transparently reported as limited to preserve 100% data integrity without fabricating statistics.
